# 🚗 Projeto Los Santos RP

> Uma reformulação completa do Modo História do GTA V, focada em interpretação de papéis (RP), sobrevivência, economia, imersão e modo cooperativo opcional.

---

## 🎯 Objetivo

Criar uma experiência de RP dentro do GTA V Story Mode, permitindo ao jogador viver uma jornada completa sem depender de servidores online.
